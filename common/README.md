# ghostkey-common (frozen copy)

This is the `ghostkey-common 0.3.0` the deployed ghostkey delegate is built
from, and the directory 0.1.0 to 0.3.0 were published from. It is no longer
published: the crate on crates.io is released from
[`crates-io/ghostkey-common/`](../crates-io/ghostkey-common/), whose README is
the one to read and edit. See "Why two copies of ghostkey-common" in the
repository README.
